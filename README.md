# Portfolio – La Nguyen Phuc Thanh
React + Vite + Tailwind CSS 3 + TypeScript + shadcn/ui + Framer Motion

    npm install
    npm run dev      # chạy thử
    npm run build    # build production (thư mục dist/)

- Sửa nội dung: `src/data/portfolio.ts` (điền `github`, `linkedin` để hiện icon)
- Đổi ảnh: thay `public/avatar.jpg`
- Màu / font: `tailwind.config.ts`
- Thêm component shadcn khác: `npx shadcn@latest add <component>` (đã có components.json)
- Hiệu ứng dùng chung: src/components/fx.tsx (Reveal, CountUp, Magnetic, Tilt, Marquee, ScrollProgress)
